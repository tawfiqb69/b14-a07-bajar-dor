# 🛒 বাজার দর | BazarDor

## 📝 Project Description

বাজার দর (BazarDor) is a Bengali-language web application that helps users explore daily prices of essential products and compare prices across different markets in Bangladesh.

## 🛠️ Technologies Used

* Next.js 16 (App Router)
* React 19
* JavaScript (JSX)
* Tailwind CSS 4
* daisyUI 5
* Better Auth
* MongoDB
* react-hot-toast

## ✨ Key Features

1. **Daily Price Overview:** View the latest prices of essential products in one place.
2. **Price Trends:** Explore products with increasing and decreasing prices.
3. **Product Details:** View minimum, maximum, average, and market-wise prices.
4. **Category Browsing & Sorting:** Browse products by category and sort them by price.
5. **Secure Authentication:** Sign up and sign in using email/password, Google, or GitHub, with protected routes.
